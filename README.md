## Selected Engineering Work

### Exam Question Manager — public
Full-stack application for managing multiple-choice exam questions.

- **Backend:** Go + Fiber
- Layered backend architecture: **handler → service → repository**
- Pagination, input validation, structured API errors, and persistence
- Repository abstraction designed so storage can be replaced without changing higher layers

Repository: https://github.com/Yuttakarn2545/exam-question-manager
